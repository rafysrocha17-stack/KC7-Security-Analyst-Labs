# 🛡️ KC7 - Laboratórios de Analista de Segurança

Este repositório foi criado para documentar meus estudos e atividades práticas de cibersegurança realizadas na plataforma KC7.

## 🎯 Objetivo

Desenvolver habilidades práticas voltadas para a atuação como Analista de Cibersegurança Júnior, especialmente nas áreas de SOC e Blue Team.

## 🔎 Conhecimentos praticados

- Análise de logs
- Investigação de eventos de segurança
- Identificação de atividades suspeitas
- Investigação de incidentes
- KQL (Kusto Query Language)
- Threat Intelligence
- Blue Team
- SOC (Security Operations Center)
